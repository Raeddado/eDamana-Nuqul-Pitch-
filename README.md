# eDamana Nuqul Group Presentation

GitHub Pages ready version.

## Deploy
1. Create or open a GitHub repository.
2. Upload everything in this folder to the repository root, including `.nojekyll`.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Open the GitHub Pages URL after deployment finishes.

## Present
- Right Arrow / Space: next slide or authored story beat.
- Left Arrow: previous slide.
- `F`: enter/exit browser fullscreen.
- Double-click the presentation: enter/exit fullscreen.
- `Esc`: exit fullscreen.

The browser requires a user gesture before true fullscreen can start, so a webpage cannot legally open itself in fullscreen automatically.
